# Chrome Web Store listing

## Name

Responsiveness — Dual Viewport Tester

## Summary (≤132 characters)

Compare mobile and tablet layouts of any page side by side. Scroll and click each viewport independently.

## Description

Responsiveness opens the page you are testing in two live viewports at once:

• Left: phone presets (iPhone 15 Pro, Pixel, Galaxy, and more)
• Right: tablet and desktop presets (iPad Pro, laptop, Full HD)
• Independent scroll and clicks in each frame
• Same Chrome profile — no extra login browser
• Fit-to-window scaling while keeping the real CSS pixel size
• Optional dual real windows when a site blocks iframes

How to use
1. Open a website.
2. Click the Responsiveness icon, then “This tab” (or paste a URL).
3. Allow access for that site when Chrome asks.
4. Scroll the left frame to review the mobile layout and the right frame for tablet.

Privacy
The extension has no accounts, ads, or analytics. Recent URLs and device choices stay in your browser. Optional site access is used only to render the URL you choose in the tester.
